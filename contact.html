Good reasons to write

  • A flag looks wrong — a missing country, a wrong image, a name you disagree with.
  • A device problem — which phone, which Android version, and what happened.
  • Feature ideas — modes, languages, accessibility.

Copyright and removal requests

Flag artwork is sourced from flagcdn.com. If you hold rights to an asset used here and want it removed, open an issue on GitHub with the exact file name and a description of the work.
